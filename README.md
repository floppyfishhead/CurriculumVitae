# 🌐 Personal Curriculum Vitae Website

> A modern, responsive personal portfolio and curriculum vitae website showcasing my engineering background, software development skills, AI expertise, and professional experience.

---

## 📖 Overview

This project is a single-page responsive web application designed to serve as my professional online presence. It provides visitors with an overview of my experience, technical skills, project portfolio, and contact information in a clean and modern interface.

The website was built as part of my continued transition into full-stack software engineering and Artificial Intelligence development while leveraging years of engineering and technology management experience.

---

## ✨ Features

- 🏠 Professional landing page
- 📄 Interactive resume/CV
- 💼 Engineering & software development portfolio
- 📬 Contact page
- 📱 Responsive design for desktop, tablet, and mobile
- ⚡ Fast loading single-page application
- 🎨 Modern UI with Bootstrap
- 🔧 Built with reusable React components

## 💻 Local Development

Clone the repository

```bash
git clone https://github.com/floppyfishhead/CurriculumVitae.git
```

Navigate to the project

```bash
cd CurriculumVitae
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm start
```
